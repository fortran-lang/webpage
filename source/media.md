# Media and Branding

This page links a set of resources to help you show your love of Fortran!

## The "F" logo

### Description

The "F" logo was designed by Jacobs William with the violet color being selected by Milan Curcic. The design is based after the cover of the original IBM Fortran programmer's reference manual from 1956. The logo is the letter "F" in a `Clarendon BT` font on a violet background with rounded edges.

## The "Powered by Fortran" logo

### Description

The "Powered by Fortran" logo was created by Sebastian Mutz and iterated in a [community-driven discussion](https://fortran-lang.discourse.group/t/powered-by-fortran/11172/62) that was initialised by Austen Rainer of the [Fortran Future Network+](https://www.fortranfuture.net/). It uses same shade of violet as the "F" logo, `DejaVu Sans Bold` for "powered by", and the `Libre Clarendon Wide` (Medium Expanded) font for "Fortran". It may be used to visually promote Fortran in your projects. You may, for example, use it in your code repository `README` file, user manuals, or conference presentations. 

### Versions

Several versions and variants were created for more flexibility. For each version, there is an upper case ("Powered by") and lower case ("powered by") variant. The `badge` and `stacked` versions also have a frameless variant.
